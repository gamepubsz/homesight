# homesight

Interactive landing page prototype for a home listing experience that gives users what they need immediately when they arrive.

## What it does

- Presents instant visitor-intent options (tour, price, financing, details)
- Dynamically updates recommended actions based on selected intent
- Includes an "Ask the House Concierge" input for quick guidance
- Shows neighborhood highlights and critical at-a-glance property facts

## Run locally

Because this is a static single-page site, you can open `index.html` directly in a browser.

If you prefer serving it over HTTP:

```bash
python -m http.server 8080
```

Then visit `http://localhost:8080`.
